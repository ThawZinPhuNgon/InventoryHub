# InventoryHub - Full-Stack Integration Project

InventoryHub is an integrated, full-stack application optimized for performance and reliability using Microsoft Copilot.

## Features & Implementation
- Built using C# ASP.NET Core Web API and JavaScript.
- Standardized API JSON response structures.
- Optimized performance using async/await and memory caching.

## Reflection
This project demonstrated the end-to-end integration of modern web technologies using AI support.
