# InventoryHub - Full-Stack Integration Project

## Project Overview
InventoryHub is a full-stack application connecting an ASP.NET Core API backend with a frontend interface, developed using Microsoft Copilot assistance.

## Implementation Details
1. **Front-End & Back-End Communication:** Built API integration endpoints using ASP.NET Core controllers and HTTP client calls.
2. **JSON Structures:** Created standardized data transfer objects (`InventoryModel.cs`) for API communication.
3. **Debugging with Copilot:** Used Copilot to identify and resolve CORS configurations and missing payload mappings.
4. **Performance Optimization:** Applied async/await pattern suggestions from Copilot to optimize payload responses and lower latency.

## Reflective Summary on Copilot Integration
Microsoft Copilot assisted throughout the development lifecycle by generating boilerplate C# integration code, diagnosing cross-origin API request errors, structuring JSON responses, and suggesting performance refactoring.
